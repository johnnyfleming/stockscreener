# Privacy Policy — TradeScreener AI

**Last Updated:** March 29, 2026

## Overview
TradeScreener AI ("the App") is a stock, cryptocurrency, and commodity market screener for Android. This Privacy Policy explains what information the App accesses, how it is used, and your choices.

## Information We Do NOT Collect
- **No personal information**: The App does not require registration, login, or any personal identifiers.
- **No tracking or advertising**: The App contains no ads, no ad SDKs, and no behavioral tracking.
- **No analytics on your portfolio**: Your watchlist, portfolio holdings, and price alerts are stored **only on your device** and are never transmitted to our servers or any third party.

## Information the App Uses

### Device Storage (Local Only)
The App stores your preferences, watchlist, portfolio, and alert settings locally on your device using Android DataStore. This data never leaves your device.

### Network Requests
The App makes network requests to the following third-party financial data APIs solely to display market data:

| Provider | Purpose | Data Sent |
|----------|---------|-----------|
| Yahoo Finance | Stock/commodity quotes & charts | Ticker symbols only |
| CoinGecko | Cryptocurrency market data | Coin IDs only |
| CoinPaprika | Cryptocurrency fallback data | Coin IDs only |
| Finnhub | Stock quotes fallback | Ticker symbols + API key |
| AlphaVantage | Stock data fallback | Ticker symbols + API key |
| Polygon.io | Commodity/stock data | Ticker symbols + API key |
| NewsAPI | Financial news headlines | Search queries + API key |
| alternative.me | Fear & Greed Index | No user data |
| Binance | Crypto price data | Trading pairs only |

No personal data, device identifiers, or location data is included in these requests.

### Firebase (Crash Reporting & Analytics)
The App uses Firebase Crashlytics to collect anonymous crash reports and Firebase Analytics for basic usage statistics (e.g., screen views). This data is processed by Google under their [Firebase Privacy Policy](https://firebase.google.com/support/privacy). No personally identifiable information is collected.

## Data Sharing
We do **not** sell, share, or transfer your data to any third parties, except as described above for displaying market data and crash reporting.

## Data Security
- All network traffic uses HTTPS encryption.
- API keys are stored securely in the application build and are not exposed to end users.
- Local data is stored in the app's private storage directory, accessible only to the App.

## Children's Privacy
The App is not directed at children under 13. We do not knowingly collect any information from children.

## Changes to This Policy
We may update this Privacy Policy from time to time. Changes will be reflected in the "Last Updated" date above.
